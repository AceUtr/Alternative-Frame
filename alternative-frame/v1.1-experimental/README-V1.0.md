# Alternative-Frame v1.0 工作副本

当前目录是从 v0.1 创建的 1.0 开发副本。代码入口和 Demo 入口与 v0.1 保持一致；版本差异、清洁规则和未完成边界见 `VERSION.md`。

## 目录原则

- `core/`：编排、合同、长程控制、模型客户端、通信和记忆。
- `domains/`：科研与软件工程领域能力。
- `tests/`：自动化测试。
- `validation/`：四类贡献门禁。
- `docs/`：设计、验收和项目管理文档。
- `runs/`：首次运行时生成，属于运行时产物，不应提交进版本。

## 版本管理要求

每次对 v1.0 做功能修改，都要同步记录验收命令、结果、运行 ID 和已知限制。若修改涉及 v0.1 已冻结的接口，先在项目管理文档中登记兼容性影响，再进行实现。
