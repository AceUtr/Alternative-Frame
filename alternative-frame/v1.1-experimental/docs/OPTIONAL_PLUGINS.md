# 主界面可选插件与比赛对照

本版保留原界面，增加一行插件摘要和“选择插件…”按钮。点击后勾选、全选或全部关闭，再点“应用”。适用于 API 模型的“标准多 Agent”和“长程任务”；固定 Demo / Stub 仍走原路径，不会假装启用这些插件。默认全部关闭。

## 四项选择的实际行为

| 选项 | 接入位置与效果 | 边界 |
|---|---|---|
| BM25 运行记忆 | 子任务执行前检索，任务验收后保存带来源的结果；重启从本运行日志重载；每次最多 3 条且检索内容上限 4500 字符 | 词法检索，未启用向量模型；历史陈述不是当前事实；已登记产物哈希变化会排除该条 |
| 依赖消息传递 | 从当前 DAG 依赖结果通过有界消息总线投递摘要，注入真实 Agent 请求 | 保留原依赖上下文，因此可能增加 token；不是自由拓扑群聊，不保证节省费用 |
| SQLite 执行队列 | 任务实际执行前入队、按 ID 认领，验收后记录结果；运行独占锁释放后可恢复废弃租约 | DAG 与原状态/产物校验仍决定调度和重跑；done 表示处理结束，结果仍可能 failed；外部副作用不保证恰好一次 |
| 用量交叉审计 | 真实 API 检查点触发 CostGuard 对累计已结算 token 的增量审计 | 不建立第二套拦截限额；原 ModelCallBudget 保持权威；未确认/估算用量仍看 api_usage.json，费用与输入输出拆分未知 |

## 使用步骤

1. 确认旧 UI 没有活动任务，关闭旧窗口，从本版本运行 `python ui.py` 或 UI 启动 bat。
2. 选择 API 模型、填写自己的配置，选择“标准多 Agent”或“长程任务”。
3. 点“选择插件…”，选择组合并应用。主界面显示选择摘要。
4. 使用独立空目录启动新任务；检查合同预览，再确认执行。插件选择一旦启动即固定；运行中修改会被阻止，恢复自动沿用保存配置。
5. 在协作日志检查 plugin_memory_retrieved / plugin_messages_delivered / plugin_task_claimed / plugin_usage_audited 等真实事件。
6. 历史任务不能因恢复而切换插件；没有插件配置的旧运行按 OFF 处理。已完成运行只作历史记录，不重复恢复。新对照实验必须新建任务。

## 证据位置

长程：`runs/long_horizon/<run_id>/`；标准：`runs/user_tasks/<run_id>/`。

- `execution_metadata.json`：实际执行源码哈希、HEAD、已跟踪脏状态、模型、预算和每次启动配置。KEY 不保存。
- `confirmed_contract.json`：长程运行确认后的合同。
- `plugins/config.json`：插件组合与目标哈希；不一致拒绝恢复。
- `plugins/audit/events.jsonl`：插件检索注入、消息、队列和用量审计事件。
- `plugins/memory/events.jsonl`：可恢复、脱敏的记忆记录。
- `plugins/tasks.sqlite3`：认领与执行结果。

插件配置和证据写入失败会停止运行，不静默关闭插件。仅做运行级隔离，不是针对恶意内容的安全沙箱；Shell 权限与原版本一致。不要把密钥放进任务文本或产物。

## 比赛 OFF/ON 对照

最少三组：全部关闭、仅 BM25、全部开启。使用同一份本版代码、同模型/线路/预算/工具、同一目标与合同，独立空目录；建议每组至少 3 次，交错运行，保留所有失败及人工干预。第一次确认的合同存于 confirmed_contract.json；其他运行在预览的 JSON 编辑器中使用同一合同并核对目标，不让不同自动合同改变难度。

主指标是独立验收通过率，辅助指标是首次通过率、任务/工具失败与重试、实际请求、usage 来源、总耗时和人工干预。对价格未知的服务不填写“成本为零”。BM25 只在任务间检索，不自动改变规划器和最终语义评审，也不解决上游账号池不可用。

旧任务历史缺少完整版本来源，只能作为背景，不能将“旧代码无插件”对“新代码有插件”的全部差异归因于插件。新增代码同时包含恢复模式保护等修复，必须在同一版代码内做 OFF/ON。没有真实对照结果前，PPT 可展示接入路径与已验证机制，不写提升百分比。

## 历史数据整理

`scripts/export_api_baseline.py --output <本地证据目录>` 只读取本项目 runs，输出 JSON 和 Markdown，附源文件哈希及脱敏快照；不会访问供应商。取每个运行最后的累计用量，不累加 sessions。计数不全、状态与用量快照不一致、费用未知等情况会明确保留。该导出不包含其他归档副本，未知旧实验不能凭对话填入为已核实结果。
