# 智联群策展示版 UI

展示版入口是 `ui_presentation.py`，保留原有 `ui.py`。展示版以 `codex/dynamic-fault-recovery` 的当前 UI 为基线，并保留运行中追加验收条件等能力。

## 启动

双击 `启动展示版UI.bat`，或在本目录运行：

```text
python ui_presentation.py
```

需要安装带 `tkinter` 的 Python 3。

## 界面

- 主界面突出任务目标、模型/API、任务执行和协作记录。
- 科研场景和开发者模式收进“更多设置”。
- 预算与执行限制默认折叠，连接测试仍在主界面。
- 运行历史、端边云视图和最新产物目录收进“更多操作”。
- 插件栏显示启用数量；插件组合仍可按需选择。
- 长程任务运行时保留追加验收条件入口。

## 回退

继续启动 `ui.py` 即可使用原版界面。展示版为独立入口，不覆盖 `ui.py`。
